# Portfolio

Mon portfolio : applications web, outils JavaScript, simulations interactives et projets Arduino.

**▶ Démo en ligne : [https://yoannservices.github.io/portfolio/](https://yoannservices.github.io/portfolio/)**

## Fonctionnalités

- Sections Accueil, À propos, Projet phare, Projets, Compétences et Contact
- Sélection de 8 projets avec liens vers leurs démos
- Fond animé en 3D

## Lancer en local

Aucune installation : ouvrez `index.html` dans un navigateur, ou servez le dossier :

```bash
python -m http.server 8000
```

puis allez sur http://localhost:8000 (dans le dossier `web/` de Mes Projets : http://localhost:8000/developpement/portfolio/).

## Structure

- `index.html` : la page
- `style.css` : les styles
- `script.js` : la logique

## Technologies

HTML, CSS et JavaScript ; rendu 3D avec [Three.js](https://threejs.org/) r128 (chargé depuis un CDN). Sans étape de build.
